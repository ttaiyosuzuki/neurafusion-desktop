NeuraFusion Desktop — Windows

────────────────────────────────────────────────
入れかた
────────────────────────────────────────────────

1. ダウンロードした zip を右クリック →「すべて展開」
   ★ 展開せずに zip の中から直接実行すると失敗します ★
2. 展開先の「インストール.cmd」をダブルクリック
3. 青い画面が出たら「詳細情報」→「実行」を押す
4. 黒い画面で導入が進みます


────────────────────────────────────────────────
なぜ青い警告が出るのか
────────────────────────────────────────────────

このファイルにはコード署名がついていません。
Windows SmartScreen が

  「Windows によって PC が保護されました」

と出して止めます。「詳細情報」を押すと「実行」が
現れます。

署名には EV コード署名証明書（年 数万円〜）が必要で、
まだ取得していません。取得したら、この警告は出なく
なります。


────────────────────────────────────────────────
必要なもの
────────────────────────────────────────────────

Node.js 24 以上   https://nodejs.org/  （LTS を選ぶ）

入っているか確かめるには、PowerShell で:

    node -v


────────────────────────────────────────────────
入れたあと
────────────────────────────────────────────────

    neurafusion onboard      最初の設定
    neurafusion --help       できることの一覧

鍵は、この端末の 資格情報マネージャー
（Windows Credential Manager）に入ります。
当社のサーバーには送られません。


────────────────────────────────────────────────
消しかた
────────────────────────────────────────────────

    npm uninstall -g openclaw

設定ごと消すときは、エクスプローラで

    %USERPROFILE%\.openclaw

のフォルダを削除してください。
