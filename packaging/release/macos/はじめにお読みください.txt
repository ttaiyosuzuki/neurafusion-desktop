NeuraFusion Desktop — macOS

────────────────────────────────────────────────
入れかた
────────────────────────────────────────────────

1. この zip を展開します（もう展開済みならそのまま）
2. 「NeuraFusion をインストール.command」を
   ★ 右クリック → 「開く」★ で実行します
3. 出てきた確認で「開く」を押します
4. ターミナルが開いて導入が進みます


────────────────────────────────────────────────
なぜ「右クリック → 開く」なのか
────────────────────────────────────────────────

このファイルには Apple の署名がついていません。
ふつうにダブルクリックすると、macOS が

  「開発元が未確認のため開けません」

と出して止めます。右クリックから開くと、その一度だけ
許可する選択肢が出ます。これは macOS の仕様です。

署名は Apple Developer Program（年 US$99）の登録が
必要で、まだ取得していません。取得したら、この手順は
不要になります。

どうしても開けないときは、ターミナルで:

    xattr -d com.apple.quarantine "NeuraFusion をインストール.command"

を実行してから、もう一度ダブルクリックしてください。


────────────────────────────────────────────────
必要なもの
────────────────────────────────────────────────

Node.js 24 以上   https://nodejs.org/  （LTS を選ぶ）

入っているか確かめるには、ターミナルで:

    node -v


────────────────────────────────────────────────
入れたあと
────────────────────────────────────────────────

    neurafusion onboard      最初の設定
    neurafusion --help       できることの一覧

鍵は、この端末の Keychain に入ります。
当社のサーバーには送られません。
